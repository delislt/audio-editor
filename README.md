# 🎵 Real-Time Audio Editor

A professional audio editor that runs **entirely in your browser**.  
Real-time processing, advanced effects, precise monitoring, and offline rendering without any backend.

Perfect for DJs, producers, podcasters, gamers, and audio enthusiasts.

---

## ✨ Highlights

✔ 100% browser-based  
✔ No installation required  
✔ Works on desktop, tablet, and mobile  
✔ Professional gain staging to prevent clipping  

---

## 🎛️ Real-Time Controls

### Gain & Dynamics
- **Pre Gain** (-24 to 0 dB) → Adjusts headroom before effects  
- **Output Gain** (-12 to +6 dB) → Final output level  
- **Limiter / Anti-Clip** → Adjustable threshold (-12 to -3 dB)  
- **Auto Reduction** → Automatically lowers gain if clipping is detected  

### EQ
- **Bass Boost** (0 to +20 dB at 200 Hz)  
- **Treble** (-15 to +15 dB at 3000 Hz)  
- Automatic compensation when bass is pushed high  

### Spatial Effects
- **Reverb** (0 to 100%)  
- **Echo / Delay** (0 to 100%)  
- **Stereo Pan** (-100 to +100)  
- **3D Spatial Audio** using HRTF  
- **8D Audio** with adjustable motion speed  

### Playback
- **Speed** (0.5x to 2.0x) without changing pitch  
- **Pitch Shift** (-12 to +12 semitones)  
- **Volume** (0 to 150%)

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| Space / K | Play / Pause |
| ← / → | -5s / +5s |
| J / L | -10s / +10s |
| Home / End | Start / End |
| ↑ / ↓ | Volume ±5% |
| M | Mute |

## 📥 Import & Export

**Input:** MP3, WAV, OGG via drag & drop or file picker.  
**Output:** WAV file, normalized, with all effects applied.  
Rendered offline before download for maximum quality.
